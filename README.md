# SpaceAgriSim

Space Agriculture & Life Support Simulator.

An interactive simulator that models how space/environmental conditions
(gravity, radiation, water, light, CO2) affect crop growth and the life-support
metrics that come with it (water use, water recovery, CO2 removal, O2 production).

> Phase 1 is a mathematical simulation prototype. NASA GeneLab/OSDR data
> integration and machine learning are planned for later phases.

## Layout

```
frontend/   React + Tailwind dashboard
backend/    FastAPI service that runs the simulation engine
```

More details will land here as Phase 1 takes shape.
